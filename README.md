# かなでスタジオ

キーの音しか置けないから、ハズレの音が出ない。超初心者向けのブラウザ作曲アプリ（DTM）です。

**▶ 遊ぶ: https://gf26a059.github.io/kanade-studio/**

## できること

- **外れた音は打てない** — メロディ欄には選んだキーの7音だけが並びます。キーを変えると自動で移調。
- **次のコードを提案** — 前のコードに合う順に★付きで候補を表示。王道進行・カノン進行などのテンプレートも。
- **プリセット10種** — Kawaii Future Bass／ヴィヴァルディ「冬」サビ（原譜から採譜）／「冬」前奏風／オーケストラ／ロック／Lo-fi チル／EDM ハウス／チップチューン／J-POP バラード／シンセウェイブ
- **おまかせメロディ・おまかせコード**、音色・弾き方・ドラムパターンの切り替え、リバーブ・スウィング・ポンピング
- **音づくり** — 立ち上がり・のび・余韻・明るさ・歪み・ビブラート・厚みなど、音ひとつの質感をつまみで調節
- **16分音符グリッド・16小節**、上級者向けの「半音ずらし」（キー外の音を例外として置ける）

音はすべて Web Audio API でブラウザ内合成しています。インストール不要、`index.html` 1ファイルで動きます。
